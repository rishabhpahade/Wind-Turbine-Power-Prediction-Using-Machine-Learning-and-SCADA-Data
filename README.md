# Wind-Turbine-Power-Prediction-Using-Machine-Learning-and-SCADA-Data
Wind energy is a rapidly growing renewable source. Wind turbines collect SCADA data, including wind speed, rotor speed, blade pitch, temperature, and power output. This project uses machine learning to predict turbine power output from historical SCADA data, providing a simple data-driven approach for renewable energy analysis.
